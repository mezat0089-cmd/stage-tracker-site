Stage tracker

Each stage sends a WhatsApp update to your team leader for audit.

First, add the team leader's WhatsApp number in the Settings tab.

    Member

    With a key, stage updates send automatically. Without one, WhatsApp opens with the message ready to send.

    Optional. Connects everyone to the leader's Google Sheet: each member's own times, and the Brief tab.

    How the team leader gets an API key
    1. Save +34 644 05 92 17 in the phone's contacts.
    2. Send that contact this WhatsApp message: I allow callmebot to send me messages
    3. The key arrives in a reply, usually within 2 minutes. Type it above and save.

    Messages then arrive from the CallMeBot contact. CallMeBot is a free third-party service, so keep task names free of confidential details.

    How the team leader connects a Google Sheet
    1. Create a new Google Sheet, then open Extensions → Apps Script.
    2. Replace the code there with the Stage Tracker script, save, choose setup and press Run. Allow access when Google asks.
    3. In the sheet's Schedule tab, type each member's name and their four times, like 09:00.
    4. Back in Apps Script: Deploy → New deployment → Web app, execute as Me, access Anyone. Copy the link that ends in /exec.
    5. Paste that link above on every phone and save.

    Anyone with the link can read the schedule and add rows, so share it only with the team.
